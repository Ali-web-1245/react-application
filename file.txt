Is React (Vite) e-commerce frontend ko backend API se connect karna hai. 
IMPORTANT: Sirf product DATA ko static arrays se hatakar backend se fetch karna hai. 
Design, layout, CSS, responsive behavior, colors, spacing — kuch bhi NAHI badalna. 
UI bilkul pixel-to-pixel same dikhna chahiye, sirf data source change hoga.

Backend live hai: https://backend-e-commerce-uuxn.onrender.com/api

STEP 1 — Setup:
- Root mein .env file banao: VITE_API_URL=https://backend-e-commerce-uuxn.onrender.com/api
- axios install karo
- src/services/api.js banao: axios instance, baseURL = import.meta.env.VITE_API_URL

STEP 2 — Products ko API se fetch karo (sirf data badlo, JSX/styling mat chhedo):
- ShopProducts.jsx mein jo SHOP_PRODUCTS_DATA hardcoded array hai usay hatao, uski jagah useEffect 
  ke andar api.get("/products") call karke response ko state mein rakho, phir wahi state render karo 
  jahan pehle static array render ho raha tha. Component ka JSX/markup/className bilkul same rakho.
- Same tareeqa TopSelling.jsx, NewArrivals.jsx, RelatedProducts.jsx mein apply karo — in sab mein 
  jo bhi hardcoded product arrays hain unko API call se replace karo, markup/styling untouched rakho
- Agar data abhi load ho raha ho to simple "Loading..." text dikhao (extra styling nahi, bas functional)

STEP 3 — Product detail page:
- App.jsx mein route "/product-details" ko "/product-details/:id" karo (sirf route path, 
  Layout/Page component wahi rakho)
- ProductCard.jsx mein jahan se "/product-details" par Link jata hai, wahan product ka id bhi 
  pass karo URL mein
- ProductDetail.jsx (jo bhi component hai) mein useParams se id nikal kar api.get(`/products/${id}`) 
  call karo, response ka data wahi fields mein dikhao jahan pehle static data dikhta tha

STEP 4 — Cart (sirf agar already koi "Add to Cart" button functional nahi hai to hi karo):
- CartItems.jsx mein jo INITIAL_CART_ITEMS hardcoded hai usay hatao
- Ek simple CartContext banao (naya file src/context/CartContext.jsx), Add to Cart button click par 
  item isme add ho, aur localStorage mein save ho
- Cart.jsx/CartItems.jsx isi context se data len, markup/styling same rakho

STEP 5 — Checkout:
- Checkout form submit hone par api.post("/orders", {items, customerInfo, ...}) call karo, 
  success par cart clear karo

Har file mein sirf wahi minimum change karo jo data-fetching ke liye zaroori hai. 
Koi naya CSS, koi naya design element, koi responsive fix mat karna — sirf data connection.
Har step ke baad batana kaunsi file mein kya add/change hua.







STEP 6 — Product Details Page Fix Karo (Priority Issue)

Problem: Kisi bhi product (NEW ARRIVALS ya TOP SELLING section mein) par click karne se 
product details page open nahi ho raha. Is poore flow ko check aur fix karo:

1. ProductCard.jsx (ya jahan bhi product card render hota hai NEW ARRIVALS/TOP SELLING/ShopProducts mein) 
   mein dekho ke Link/navigate call mein product ka _id (MongoDB se aane wala id) sahi se URL mein 
   pass ho raha hai ya nahi. Example sahi tareeqa:
   <Link to={`/product-details/${product._id}`}>

2. App.jsx mein route check karo — "/product-details/:id" (ya jo bhi param naam use kiya hai) 
   exactly match karna chahiye Link ke URL pattern se.

3. ProductDetail.jsx (ya jo bhi component product details page render karta hai) mein:
   - useParams() se id nikal rahe ho confirm karo (import { useParams } from "react-router-dom")
   - useEffect ke andar api.get(`/products/${id}`) call ho rahi hai confirm karo
   - Response se jo product data aaye wahi fields (title, price, image, description, rating waghera) 
     render ho rahe hon, placeholder/static data nahi
   - Agar id undefined ya null ho to console mein warn karo taake debug easy ho

4. Test karo: Home page ke NEW ARRIVALS section mein kisi bhi product (jaise "Checkered Shirt") 
   par click karke confirm karo ke:
   - URL change hoke /product-details/<actual-mongodb-id> banta hai
   - Us product ka sahi data (title, price, image, description) detail page par show hota hai
   - Koi console error na aaye

5. Yahi check NEW ARRIVALS, TOP SELLING, aur ShopProducts (Shop page) teeno jagah se karo — 
   sab jagah se click karne par sahi product detail khulna chahiye.

STEP 8 — Frontend Ko Fully Responsive Banao

Problem: E-commerce customer frontend abhi responsive nahi hai — mobile aur tablet screens 
par layout bigad jata hai (overflow, overlapping elements, chhoti screens par bade fonts/images waghera).

IMPORTANT: Design ka look (colors, fonts, spacing proportion, overall style) change nahi karna — 
sirf alag screen sizes (mobile, tablet, desktop) par sahi se adjust hona chahiye. Koi naya 
design element ya feature add nahi karna, sirf responsive banana hai.

Scope — in breakpoints ke liye test aur fix karo:
- Mobile: 375px aur 390px width
- Tablet: 768px width
- Desktop: 1280px aur 1440px width (ye already theek honi chahiye, baseline hai)

Har page/component check karo aur fix karo:
1. Navbar/Header — mobile par hamburger menu honi chahiye (agar nahi hai to banao), logo aur 
   icons overlap na hon, search bar chhoti screen par theek fit ho
2. Home page sections — Hero banner, NEW ARRIVALS, TOP SELLING: grid jo desktop par 4 columns 
   mein hai, mobile par 1 ya 2 columns mein stack honi chahiye (CSS grid/flexbox media queries se), 
   images apna aspect ratio maintain karte hue scale hon, text overflow na ho
3. Shop/Products listing page — filter sidebar mobile par collapsible/drawer ban jaye (ya niche 
   stack ho jaye), product grid responsive columns adjust kare
4. Product Detail page — image aur info section mobile par side-by-side ki jagah upar-niche stack 
   hon, buttons full-width ho jayen chhoti screen par
5. Cart page — cart items table/list mobile par horizontally scroll na kare, readable rahe, 
   quantity controls aur remove button accessible rahen
6. Checkout page — form fields full width hon mobile par, labels/inputs properly stacked hon
7. Footer — links/columns mobile par stack hon, overflow na ho

Technical approach:
- Jahan bhi fixed pixel widths hain unhe relative units (%, rem, max-width, min-width) ya 
  CSS Grid/Flexbox ke saath replace karo jahan zaroorat ho
- Media queries use karo (@media (max-width: 768px), @media (max-width: 480px) waghera) — 
  jo bhi CSS structure project mein already hai (plain CSS files per component) usi pattern 
  ko follow karo, naya CSS framework mat add karo
- Images par max-width: 100%, height: auto lagao taake overflow na ho
- Horizontal scroll (body ya kisi container ka) kahin na ho kisi bhi screen size par — ye 
  sabse important check hai

Verify (headless browser, in viewport sizes par screenshot le kar):
- 375px width par: Home, Shop, Product Detail, Cart, Checkout — in sab pages par koi horizontal 
  overflow na ho, saara content readable aur accessible ho
- 768px width par: same check
- 1280px/1440px: design pehle jaisa hi dikhna chahiye, kuch bigadna nahi chahiye

Har file mein jo change karo wo batana, aur sab breakpoints ke screenshots (ya confirmation) 
ke saath verify karna ke responsive ho gaya hai.
